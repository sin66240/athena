# Athena

AI Poker Framework

Athena is a modular AI framework designed for poker simulation, training, evaluation, and experiment management.

The project focuses on building a complete machine learning pipeline with reusable components for agents, environments, models, training, evaluation, and self-play systems.

---

## Features

### AI & Agents

- Agent interface
- Random agent
- Rule-based agent
- AI agent architecture

### Core Poker Engine

- Cards
- Deck management
- Hand evaluation
- Player system
- Tournament system
- Betting system
- Game state management

### Machine Learning Pipeline

- Feature extraction
- Feature transformation
- Dataset management
- Model training
- Model evaluation
- Model comparison

### Training Framework

- Trainer system
- Training sessions
- Checkpoint management
- Training history tracking
- Callback system
- Early stopping support

### Experiment Tracking

- Experiment management
- Result tracking
- Hyperparameter management
- Best model tracking
